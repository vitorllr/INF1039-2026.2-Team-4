# Escolha do logo - BlueTide

## Os 5 conceitos

1. Onda-Escudo (`logos/1-onda-escudo.svg`) - um escudo com ondas dentro, remetendo a proteção.
2. Gota-Sinal (`logos/2-gota-sinal.svg`) - uma gota d'água dividida em três faixas horizontais, uma para cada cor do status.
3. Radar-de-Maré (`logos/3-radar-de-mare.svg`) - círculos concêntricos de radar sobre uma linha de onda, remetendo a monitoramento contínuo.
4. Monograma BT (`logos/4-monograma-bt.svg`) - as iniciais do app com uma onda como base.
5. Nível-da-Maré (`logos/5-nivel-da-mare.svg`) - barras de altura crescente, como um medidor de nível, com uma onda por cima.

## Escolhido: Gota-Sinal

O conceito escolhido é o Gota-Sinal (`logos/2-gota-sinal.svg`).

A gota é o símbolo mais direto e universal para "água" que existe, então não exige nenhuma explicação para quem vê o ícone pela primeira vez, diferente do escudo ou do radar, que dependem de um pouco mais de contexto para serem lidos como "app de maré e chuva". Dentro dela, as três faixas horizontais nas cores de status (`#1E8A5F` verde, `#C97A1E` amarelo, `#B23A2E` vermelho, definidas em `identidade-visual.md`) colocam a recomendação verde/amarelo/vermelho, que é o elemento mais importante do produto, dentro do próprio símbolo da marca. O logo já comunica a proposta de valor do app antes mesmo de abrir a tela principal: "aqui a água te diz se está seguro ou não".

Os outros quatro conceitos foram descartados por motivos específicos.

O Onda-Escudo comunica bem "proteção", mas não carrega o sistema de cores de status, perdendo a chance de reforçar o elemento mais reconhecível do produto. O Radar-de-Maré funciona bem como ícone de monitoramento, mas em tamanhos pequenos, como o ícone do app na tela do celular, os círculos concêntricos tendem a se fundir e perder definição. O Monograma BT é o mais genérico dos cinco: depende só da tipografia para diferenciar a marca, e um app de segurança pública se beneficia mais de um símbolo do que de duas letras. Já o Nível-da-Maré é o que mais remete a dado bruto, parece um gráfico de barras, o que é interessante para uma tela interna do app, mas é fraco como ícone de app, porque não fica claro à primeira vista que se trata de água.

A cor azul-maré (`#0B3C5D`) do contorno da gota mantém a ligação com a paleta de marca definida em `identidade-visual.md`, enquanto as três faixas internas usam exatamente as cores de status já calibradas para terem luminosidade parecida entre si. O logo funciona tanto como ícone de app quanto como uma prévia visual do próprio sistema de recomendação do BlueTide.
